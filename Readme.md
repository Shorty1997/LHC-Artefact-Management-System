The LHC Artefact Management System is a Python-based application developed to help manage artefact records for the LHC. It provides a simple, menu-driven interface for storing, viewing, searching and updating artefact information.

Features
Add new artefacts.
Update the condition of existing artefacts.
View all stored artefacts.
Search for artefacts by name.
Validate user input.
Display error messages for invalid entries.
Technologies Used
Python
PyCharm
GitHub
Data Storage

The application uses a Python list containing dictionaries to store artefact information while the programme is running.

Each artefact record contains:

Name
Category
Location
Condition
How to Run
Download the Python file from this repository.
Open the file in PyCharm or another Python environment.
Run the programme.
Follow the on-screen menu options.
